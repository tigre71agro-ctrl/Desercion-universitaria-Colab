# Deserción universitaria: análisis exploratorio con Google Colab

## Descripción del proyecto

Trabajo académico de la Unidad I del curso Ciencia de Datos e Inteligencia Artificial Aplicada.

Se realizó la preparación, documentación y análisis exploratorio de un conjunto de datos sobre abandono, permanencia y graduación de estudiantes universitarios mediante Python y Google Colab.

## Base de datos

**Fuente:** UCI Machine Learning Repository.

**Conjunto de datos:** Predict Students' Dropout and Academic Success.

**Observaciones:** 4424 estudiantes.

**Variables:** 37 originales y 2 indicadores derivados.

**DOI:** https://doi.org/10.24432/C5MC89

## Contenido del proyecto

El repositorio reúne el cuaderno de Python, el dataset procesado, el diccionario de datos, el registro de decisiones metodológicas y el informe HTML con las tablas, gráficos y conclusiones del análisis exploratorio.
